<Hook emoji="🟨">
Can you work out 103² in your head? 103² = (100 + 3)² = 10,000 + 600 + 9 = **10,609**. Or 98 × 102? It's (100 − 2)(100 + 2) = 10,000 − 4 = **9,996**. These tricks use **identities**: equations that are true for every value of the letters.
</Hook>

<PredictFirst
  question="Is (a + b)² equal to a² + b²?"
  options={["Yes, always", "No, it's a² + 2ab + b²", "Only if a = b", "Only for negative numbers"]}
  answer={1}
>
Try a = 3, b = 4: (3 + 4)² = 49, but 3² + 4² = 25. The missing 24 is 2ab = 2 × 3 × 4. So **(a + b)² = a² + 2ab + b²**.
</PredictFirst>

<DidYouKnow>
Ancient Indian and Greek mathematicians proved identities like these with **cut-and-rearrange diagrams**, just like the lab, long before modern algebraic notation existed. Euclid's *Elements* (about 300 BCE) states (a + b)² = a² + 2ab + b² as a fact about squares and rectangles.
</DidYouKnow>
