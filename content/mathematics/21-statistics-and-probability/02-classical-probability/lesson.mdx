<Stage kind="explain" title="Key ideas" />

<ConceptCard title="Theoretical probability" emoji="🎯">
If all outcomes are equally likely, **P(E) = number of favourable outcomes ÷ total number of outcomes**. 0 ≤ P(E) ≤ 1. An impossible event has probability 0; a sure event, 1. **P(E) + P(not E) = 1**.
</ConceptCard>
