<Stage kind="explain" title="Key ideas" />

<ConceptCard title="Surface area vs volume" emoji="🧩">
**Surface area**: add only the exposed surfaces. **Volume**: add the volumes of all parts (or subtract any hollows).
</ConceptCard>

<StepReveal
  steps={[
    "A toy is a cone (r = 3.5 cm, h = 12 cm) on a hemisphere (r = 3.5 cm). Take π = 22/7.",
    "Cone slant height l = √(12.25 + 144) = 12.5 cm.",
    "Curved surface: πrl + 2πr² = (22/7)(3.5)(12.5) + 2(22/7)(12.25) = 137.5 + 77 = 214.5 cm².",
    "Volume: ⅓πr²h + ⅔πr³ = 154 + 89.83 ≈ 243.83 cm³."
  ]}
/>
