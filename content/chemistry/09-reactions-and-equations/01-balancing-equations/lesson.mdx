<Hook emoji="⚖️">
When magnesium ribbon burns, it seems to vanish into a white powder. But every magnesium atom is still there, now joined to oxygen. A **balanced equation** is chemistry's way of keeping count of every atom.
</Hook>

<PredictFirst
  question="How many oxygen molecules react with 2 magnesium atoms in 2Mg + O₂ → 2MgO?"
  options={["2", "1", "4", "None"]}
  answer={1}

One O₂ molecule has 2 oxygen atoms: enough for 2 MgO.
</PredictFirst>

<ConceptCard title="Why balance?" emoji="🔒">
The <KeyTerm def="Atoms are neither created nor destroyed in a chemical reaction, so a balanced equation has the same number of each kind of atom on both sides.">law of conservation of mass</KeyTerm> says atoms are only rearranged. So the number of each kind of atom must be the same on both sides. We change only the **coefficients** (big numbers in front).
</ConceptCard>
